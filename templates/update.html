Install Mellow, or update it. Your family, places and settings stay exactly as they are.

Android phone or tablet

  1. Tap Download Mellow {{ version_name }} below.
  2. When it finishes, tap Open on the download (or find it in your notifications or the Files app).
  3. If Android asks, allow Install unknown apps for this browser, then go back.
  4. Tap Install or Update. It installs over the old one, so you stay signed in.
Download Mellow {{ version_name }}

Windows computer or iPhone

An Android app file (.apk) cannot run on Windows. Use the web version instead. It is always the newest and updates by itself.

  1. Open Mellow on the web below in Edge or Chrome.
  2. Sign in with your family code. A browser stays signed in only in the same browser, so open it in the one you use.
  3. To get its own window and icon: menu, Apps, Install this site as an app (on iPhone: Share, Add to Home Screen).
